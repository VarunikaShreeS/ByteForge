# SENTINEL AI

### Detect Threats. Protect Trust.

SENTINEL AI is a digital risk protection platform designed to help businesses identify potential brand impersonation, suspicious social media profiles, phishing websites, fake apps, and scam activity.

The goal is simple: help businesses protect their digital identity and give users an easy way to report suspicious online activity.

## Features

- **Business Registration** — Register a business and its official digital identities.
- **Threat Detection** — Investigate suspicious profiles, websites, apps, and brand impersonation.
- **Spam Reporting** — Submit suspicious links, messages, profiles, and screenshots.
- **Evidence Review** — Organize available evidence and investigation records.
- **Threat Assessment** — Review suspicious indicators, supporting evidence, and recommended next steps.

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/VarunikaShreeS/ByteForge.git
```

**2. Open the project folder**

```bash
cd ByteForge
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## How It Works

1. Choose Business Login or Spam Reporting.
2. Register a business or submit suspicious content.
3. Review available threat analysis and evidence.
4. Investigate suspicious activity and follow recommended next steps.
